# @file-viewer/svelte-full-with-opts-in

Additive **full-with-opts-in** wrapper for `@file-viewer/svelte`.

It uses `@file-viewer/preset-full-with-opts-in`: DICOM, signature/evidence containers, enhanced IFC, BPMN, Adobe/design and binary-inspector opt-ins are enabled together with the non-CAD Full matrix.

The AGPL-only CAD/DWG/DWF/DWFX runtime is intentionally not a dependency. Existing `@file-viewer/svelte-full` remains unchanged.
