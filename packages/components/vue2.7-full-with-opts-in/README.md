# @file-viewer/vue2.7-full-with-opts-in

Additive **full-with-opts-in** wrapper for `@file-viewer/vue2.7`.

It uses `@file-viewer/preset-full-with-opts-in`: DICOM, signature/evidence containers, enhanced IFC, BPMN, Adobe/design and binary-inspector opt-ins are enabled together with the complete Full matrix.

CAD/DWG/DWF/DWFX is included through the preset and `@file-viewer/renderer-cad`, with a self-hosted Worker/WASM asset pack. The CAD runtime contains AGPL/GPL components: retain its notices and corresponding-source offer when redistributing it. Existing `@file-viewer/vue2.7-full` remains unchanged.
